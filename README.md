# 사운드픽 — 10~40만 원대 음향기기 비교·제휴 미니 웹

음향기기 비교·추천 콘텐츠로 쿠팡 파트너스(또는 네이버 쇼핑 커넥트) 수익을 만드는 **정적 웹페이지**입니다.
HTML/CSS/JS가 `index.html` 한 파일에 모두 들어 있어, 빌드 도구 없이 열고 올리면 바로 동작합니다.

- 파일: `index.html` (단일 파일, 외부 라이브러리·CDN·폰트 요청 없음)
- 언어/반응형: 한국어, 모바일·태블릿·PC 대응, 다크 모드 자동 대응
- 가격 조사일: **2026년 11월 25일 · 다나와 최저가(정품) 기준**

## 3. 무료 호스팅 방법 (택 1)

세 곳 모두 **무료**이고, 정적 HTML만 올리면 됩니다. 도메인 없이 나오는 기본 주소로도 충분히 쓸 수 있습니다.

### 3-1. GitHub Pages (가장 간단, 추천)

1. GitHub에 로그인 → 우측 상단 `+` → **New repository**
2. Repository name 예: `audio-gear-hub` / 공개 범위 **Public** → `Create repository`
3. 생성된 저장소에서 `Add file` → `Upload files` → `index.html` 업로드 → `Commit changes`
4. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
5. `Build and deployment` → Source: **Deploy from a branch**, Branch: **main** / 폴더 **/(root)** → `Save`
6. 1~2분 뒤 `https://{아이디}.github.io/audio-gear-hub/` 로 접속됩니다.

- 하위 폴더 구조로 여러 페이지를 둘 계획이면, 저장소 루트에 폴더를 만들고 그 안에 `index.html`을 넣으면 `https://{아이디}.github.io/{저장소}/{폴더}/`로 열립니다.
- 수정은 웹에서 파일을 다시 업로드하거나 `git`으로 push하면 자동 반영됩니다.

### 3-2. Cloudflare Pages (속도·무료 트래픽 여유)

1. https://dash.cloudflare.com → **Workers & Pages** → `Create` → **Pages** → `Upload assets`
2. 프로젝트 이름 입력 → `index.html`을 폴더째 드래그&드롭 → `Deploy site`
3. `https://{프로젝트명}.pages.dev` 주소가 바로 발급됩니다.

- Git 연동(권장): **Connect to Git** → GitHub 저장소 선택 → Framework preset `None`, Build command 비움, Output directory `/` → 저장 시 자동 배포.
- 나중에 커스텀 도메인을 붙이기 가장 편한 곳입니다.

### 3-3. Vercel

1. https://vercel.com → GitHub로 로그인 → **Add New…** → **Project** → 저장소 Import
2. Framework Preset: **Other**, Build Command·Output Directory 비움
3. `Deploy` → `https://{프로젝트명}.vercel.app` 발급

> **네이버 블로그에 붙일 때 주의**: 네이버 블로그는 외부 HTML/iframe 삽입을 지원하지 않습니다.
> 그래서 이 페이지는 “블로그 본문용”이 아니라 **블로그에서 링크로 유도하는 독립 페이지**로 쓰는 것이 맞습니다(4장 참고).

## 4. 제휴 링크 교체 가이드 (여기만 하면 수익화 완료)

### 4-1. 쿠팡 파트너스 링크 만들기

1. https://partners.coupang.com 로그인(없으면 가입 신청) → **상품 검색**에서 위 8개 모델명을 그대로 검색
2. 상품 상세에서 **링크 만들기** → `쿠팡 단축 URL` 또는 `딥링크` 복사
   - 블로그·SNS용은 보통 **짧은 링크(shorten url)** 를 쓰면 됩니다.
   - 같은 상품이라도 판매처(로켓배송/판매자배송)가 여러 개면 **재고·가격이 안정적인 판매처**를 고르세요.
3. 복사한 주소를 `index.html` 안의 아래 블록에 붙여 넣습니다.

```js
/* index.html 안, <script> 첫 부분 */
const AFFILIATE_LINKS = {
  "sony-wh-ch720n":            "#coupang-partner-link-sony-wh-ch720n",   // ← 여기에 붙여넣기
  "sony-wh-1000xm5":           "https://link.coupang.com/a/예시코드",
  "apple-airpods-pro-3":       "https://link.coupang.com/a/예시코드",
  "bose-qc-ultra-2":           "https://link.coupang.com/a/예시코드",
  "ath-m50x":                  "https://link.coupang.com/a/예시코드",
  "scarlett-solo-4th":         "https://link.coupang.com/a/예시코드",
  "presonus-eris-35-bt-gen2":  "https://link.coupang.com/a/예시코드",
  "audioengine-a2-plus":       "https://link.coupang.com/a/예시코드"
};
```

- 값이 `#`으로 시작하면 “아직 링크가 연결되지 않음”으로 보고, 버튼을 누를 때 안내 토스트만 뜹니다. 실수로 빈 링크가 나가는 일이 없습니다.
- `https://`로 시작하는 값은 새 창에서 열리고 `rel="sponsored nofollow noopener"`가 붙어 있습니다(검색엔진·보안 관례).
- 제품을 추가하려면 `PRODUCTS` 배열에 객체를 하나 더 넣고, 같은 `id`로 `AFFILIATE_LINKS` 항목을 추가하면 카드·필터·비교표에 자동 반영됩니다.

### 4-2. 네이버 쇼핑 커넥트를 쓸 경우

- 쿠팡 파트너스와 **동시에** 쓸 수 있습니다. 쇼핑 커넥트는 네이버 블로그 등 네이버 서비스 활동자를 대상으로 하며, 신청 후 심사를 거칩니다(자세한 자격·정산 조건은 신청 화면의 최신 안내 확인).
- 링크를 바꿀 때는 같은 방식으로 `AFFILIATE_LINKS` 값만 교체하면 됩니다. 상품별로 쿠팡/네이버를 섞어도 됩니다.
- 쇼핑 커넥트는 **상품명·가격이 자동으로 갱신되는 링크**를 제공하는 경우가 있으니, 가격 변동이 잦은 제품은 그쪽이 유리합니다.

### 4-3. 꼭 지켜야 하는 표기

- 하단 고지 문구는 그대로 두세요: “이 포스팅/페이지는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.”
- 카드 하단의 “쿠팡 파트너스 활동으로 수수료를 받을 수 있습니다.”도 유지하는 편이 안전합니다.
- 가격을 “최저가”라고 쓸 때는 **조회 시점**을 함께 적으세요(이미 카드에 2026.11.25로 표기).
- 체험·협찬을 받은 제품이면 그 사실을 별도로 밝혀야 합니다.

## 5. 네이버 블로그 연동 팁

이 페이지는 “블로그 밖 랜딩 페이지”로 두고, 블로그 글에서 유입을 만드는 구조가 효율적입니다.

1. **블로그 글 1편 = 제품 1~2개 리뷰**, 본문 마지막에
   “8종 한눈에 비교표는 여기 → (배포한 주소)” 형태로 링크.
   - 네이버는 외부 링크에 `nofollow`를 붙이지만, **클릭 유도 문구**가 있으면 실제 유입은 충분히 생깁니다.
   - 링크는 `https://…` 전체 주소를 그대로 노출하세요. 단축 URL보다 신뢰도가 높습니다.
2. **키워드는 “모델명 + 상황”** 조합이 전환율이 좋습니다.
   예: `WH-1000XM5 vs 에어팟 프로 3`, `10만원대 노이즈캔슬링 헤드폰 추천`, `홈레코딩 오디오 인터페이스 입문`.
3. **표 이미지 + 링크**: 블로그 글에는 비교표를 캡처 이미지로 넣고, 이미지 아래에 “전체 스펙·최저가는 비교 페이지에서” 링크를 붙이면 클릭이 잘 됩니다.
4. **모바일 확인**: 유입의 대부분이 모바일입니다. 배포 후 꼭 폰에서 열어 필터·비교 버튼을 눌러 보세요.
5. **업데이트 주기**: 가격은 자주 바뀝니다. 월 1회 `PRODUCTS`의 `price`와 조사일을 갱신하면 “최신 정보” 신뢰가 유지됩니다.
   - 조사일은 `index.html` 스크립트 상단의 **`PRICE_ASOF` / `PRICE_ASOF_LONG` 두 값만** 바꾸면 히어로 통계·카드 가격 안내·비교창 하단·푸터 표기가 한꺼번에 바뀝니다.
   - 히어로 상단의 “2026년 11월 기준” 배지는 정적 문구이므로 함께 고쳐 주세요.
6. **글 → 페이지 → 구매** 흐름을 끊지 마세요. 페이지 안에서 제품 카드의 제휴 버튼이 바로 보이도록, 블로그에서는 “가격 비교표”를 강조하세요.

## 6. 유지보수 메모

- 제품 추가: `PRODUCTS` 배열에 `{ id, name, brand, use, price, launchPrice, tags, sound, link, target, specs }` 형식으로 추가.
  - `use`: `commute` | `work` | `desk`
  - `price`: 최저가(원 단위 숫자) — 예산 필터가 이 값으로 자동 분류(20만 미만 / 40만 미만 / 그 이상)
  - `launchPrice`: 모르면 `null`
- 제품 삭제: `PRODUCTS`와 `AFFILIATE_LINKS`에서 함께 제거.
- 제품 사진(선택): `images/` 폴더에 아래 파일명으로 넣으면 카드 우측 썸네일에 자동으로 나타납니다. 형식은 `.jpg` → `.png` → `.webp` 순으로 찾고, 셋 다 없으면 이미지 칸이 아예 숨겨집니다(깨진 이미지·빈 박스 없음).
  - `sony-wh-ch720n` · `sony-wh-1000xm5` · `apple-airpods-pro-3` · `bose-qc-ultra-2`
  - `ath-m50x` · `scarlett-solo-4th` · `presonus-eris-35-bt-gen2` · `audioengine-a2-plus`
  - 권장: 정사각 600×600px 내외, 200KB 이하, 배경 흰색 또는 투명 PNG
- 비교 개수 변경: 스크립트 상단 `const MAX_PICK = 3;`
- 문의·책임 표기: 푸터에 사업자 정보·연락처를 넣을 자리를 만들어 두지 않았으니, 수익화 규모가 커지면 추가하세요.
- 검색 노출(SEO): `<title>`, `<meta name="description">`, `<link rel="canonical">`, `og:url`을 배포 주소로 바꿔 주세요.
